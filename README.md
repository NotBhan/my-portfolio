## 🌟 About This Portfolio

This portfolio is built with **Next.js 15 App Router**, **TypeScript**, and **Tailwind CSS**. It features:
- **Modular Bento Grid Architecture**: Dark-mode glassmorphic cards optimized for quick visual scanning.
- **Dynamic Content Management System (Admin Panel)**: Secure administrative portal to manage and reorder projects, carousel slots, homepage capability cards, skills, testimonials, and stats in real time.
- **Fast Performance & SEO**: Server-side rendered pages with metadata, OpenGraph tags, sitemaps, and robots.txt.

### 🏃 Running Locally

```bash
# Clone the repository
git clone https://github.com/NotBhan/my-portfolio.git

# Navigate to the project directory
cd my-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:9002` in your browser.
